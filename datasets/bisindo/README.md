# BISINDO Dataset Layout

Place local training videos here. Do not commit raw datasets.

Suggested class folders for the MVP:

- `halo/`
- `terima_kasih/`
- `maaf/`
- `tolong/`
- `saya/`
- `kamu/`
- `ya/`
- `tidak/`
- `makan/`
- `minum/`

When possible, keep signer metadata beside each recording so train/validation/test splits can avoid putting recordings from the same signer in both training and test sets.
